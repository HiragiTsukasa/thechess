# 英語対応（多言語化）

日本語は 650件・10,970字がコード中に直接書かれていた。これを機械的に `TR()` 呼び出しへ
置き換え、辞書で差し替える方式にしている。**手作業で編集していない**ので漏れが出にくい。

## 仕組み

```
TR('回復')              辞書を引く。無ければ日本語のまま返す
TRF('{0}手目で決着', n)  語順が言語で変わるので書式文字列にする
```

`T` / `TF` ではなく `TR` / `TRF` なのは、本体に `const T=tierOf(...)` が4箇所あり
グローバルが影に隠れるため。

言語は起動時に決まる。`localStorage.nc_lang` があればそれ、無ければ端末の言語
（`navigator.language` が ja なら日本語、それ以外は英語）。`__TRlang('en')` で切替。

HTML に直接書かれた日本語（静的テキスト・aria-label 等）は**マークアップを触らず**、
起動時に `TRdom()` が DOM を走査して差し替える。CSS セレクタを壊さないため。

ルールブックは `srcdoc` の別ドキュメントだが同一オリジンなので、`parent.__TR` を借りる。

## 作り直す手順

```bash
cd tools/i18n
node transform.js --write       # TR()化して www/index.html.i18n を書く。strings.json も出る
node runtime.js dict.json       # ランタイムと辞書を差し込む
node verify.js                  # ★ TR() を剥がして元と1バイト一致するか検証
mv ../../thechess-app/www/index.html{.i18n,}   # 問題なければ差し替え
```

**注意**: `transform.js` は `index.html` を入力にする。すでに `TR()` 化された
ファイルに対して流すと二重に包まれるので、やり直すときは git から元を戻すこと。

`extract.js` は調査専用（何がどこにあるか見るだけ。書き換えない）。
`dict-{a,b,c,d,e}.json` を結合したものが `dict.json`。分けてあるのは長さ・種類ごと。

`verify.js` が通れば、**日本語モードの挙動は元と完全に同じ**だと言える
（日本語では `TR(s)===s` なので、剥がした結果が元と一致すれば変換は無害）。
辞書を差し替えるたびに流すこと。

## 注意

- `obj['あ']` のような計算プロパティと、オブジェクトのキーは置換しない（参照が壊れるため）。
  いまのコードには該当なし（0件）。
- ランクマッチの相手名は `rkOpName()` が作る。英語では `TRLANG` を見てローマ字プール
  だけを使う（和名の「の」が混ざると読めないため）。辞書は通さない。
- 盤上の漢字1文字バッジは英語で3文字の略語にしてある。
  `双`→`DBL`（Double Check） / `縫`→`PIN` / `技`→`SKL` / `力`→`PWR`。


## 日常の確認

一度 TR() 化したあとは `transform.js` を流せない（二重に包まれる）。
文言を足したり消したりしたら `check.js` を使う。

```bash
node check.js            # 未訳と、使われなくなった訳を一覧
node check.js --prune    # 使われなくなった訳を dict.json から外す
```

未訳が1件でもあると終了コード1になるので、そのまま確認に使える。
新しい日本語をコードに書いたときは、`TR('…')` で包んで `dict.json` に訳を足すこと。

`verify.js` は i18n 移行時に「変換が挙動を変えていない」ことを示すためのもので、
比較対象が移行前の index.html なので、移行後の編集には使えない。
