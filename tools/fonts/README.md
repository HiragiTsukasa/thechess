# フォントのサブセット

`www/fonts/*.woff2` は Google Fonts から**使う字だけ切り出した**ものです。
文面を足したとき、その字がサブセットに無いと、**そこだけ別の書体**で表示されます。

実際に起きた例：「対局履歴」を足したら、`履` と `歴` だけ明朝の細い字になった。
`Dela Gothic One` にも `Zen Old Mincho` にも、その2字が入っていなかった。

**日本語の文面を足したら、これを流してください。**

```
pip install fonttools brotli
python3 tools/fonts/build.py
```

`index.html` と `tools/i18n/dict.json` に出てくる仮名・漢字・記号を全部集めて切り直します。

## 注意

- **利用者が打つ名前は対象外です。** どんな字が来るか分からないので、名前を出すところ
  （順位表、対局履歴）は明朝のままにしてあります。欠けても落ち先が近い書体になります
- `document.fonts.check()` は当てになりません。欠けていても `true` を返します。
  確かめるときは、同じ文字列を2つの書体で並べて**目で見てください**
